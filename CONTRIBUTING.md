# Contributing

Thanks for your interest in this project.

This repository is Sail's fork of Verus. [SAIL.md](SAIL.md) explains what it
changes and why.

## Pull requests

We are not accepting outside contributions at this time. Pull request creation is restricted to collaborators.

Contributions to Verus itself belong upstream, in [verus-lang/verus](https://github.com/verus-lang/verus), under its contributing guide.

## Issues

The issue tracker is open for the fork's changes (see [SAIL.md](SAIL.md)), and we welcome bug reports and questions about them. Report problems in Verus itself upstream.

## Forks

This project is released under the MIT License. You are free to fork, modify, and redistribute it under the terms in [LICENSE](LICENSE).

## Security

Please report security vulnerabilities privately using GitHub's **Report a vulnerability** button on the repository's Security tab, rather than opening a public issue.

## Building and testing

To build the fork and run its regression tests, see [Build and test locally](SAIL.md#build-and-test-locally) in SAIL.md. For upstream's build and test guidance, see [BUILD.md](BUILD.md) and upstream's [CONTRIBUTING.md](https://github.com/verus-lang/verus/blob/426d8b01e7ffb910a36c15e1f870ff985bb61eef/CONTRIBUTING.md) at the pinned upstream commit.
